ELF, edited the way a linker would have written it.

go-binfmt holds pure-Go tools for binary object and executable formats. The PE/COFF and UEFI side lives in go-coff; here the format is ELF, and the first tool is the one package builders reach for when a binary must run from a different prefix than the one it was linked for.
